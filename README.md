

\# RISC-V RTL Security Verification



Research conducted with the Texas A\&M SETH Lab.



\## Overview

Investigated six reported RISC-V ISA-conformance findings

in the RSD out-of-order processor, focusing on:



\- Floating-point architectural state management

\- Privileged CSR access and permission enforcement



\## Methodology

\- Derived targeted tests from RISC-V ISA requirements

\- Simulated RTL using ModelSim/Questa

\- Analyzed architectural state, traces, and exceptions

\- Documented expected versus observed behavior



\## Technical Contributions

\- RISC-V processor verification

\- Directed test development and debugging

\- RTL simulation and architectural analysis

\- Collaborative technical reporting



\## Limitations

Findings reflect a specific historical RSD revision.

Results should not be interpreted as confirmed

vulnerabilities in current upstream releases.



Research performed collaboratively. Individual findings

and attribution are subject to publication clearance.
